* Getting started

This is an example [[https://orgmode.org][Org]] document, opened by default when
you start nimacs without a file. *Org babel mode* is already on, so this prose is
set in a proportional font while the source block below switches to monospace.

* An R source block

Put the cursor anywhere inside the block below and press =C-c C-c=. nimacs runs
the code through Rscript, captures its output, and writes a =#+RESULTS:= block
right after it (re-running updates the results in place).

#+begin_src R :results output
  # Fit a simple model on a built-in dataset
  data(mtcars)
  fit <- lm(mpg ~ wt + hp, data = mtcars)
  summary(fit)
#+end_src

* Sessions: state that persists across blocks

Add a =:session name= header and the block runs in a long-lived R process, so
variables, loaded packages, and options carry over to later blocks with the same
session name. Run the two blocks below in order (=C-c C-c= in each):

#+begin_src R :session demo
  df <- mtcars
  fit <- lm(mpg ~ wt + hp, data = df)
  coef(fit)
#+end_src

#+begin_src R :session demo
  # `fit` still exists here -- it came from the previous block
  round(summary(fit)$r.squared, 3)
#+end_src

* Next steps

- Run any =#+begin_src R= block with =C-c C-c= (needs R on your PATH).
- Add =:session name= to share state across blocks; omit it for a fresh,
  isolated one-shot run each time.
- Press =C-s= to save. This is a scratch buffer, so pass a path on the command
  line (=nimacs file.org=) to enable saving to a real file.
- Edit =config.nim= from the header bar, then Reload Config (=C-S-r=) to
  hot-swap your keybindings while the app keeps running.
